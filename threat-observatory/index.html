Die Karte darf spektakulär animiert sein, aber jeder technische Punkt besitzt eine echte Quelle und einen klaren Gültigkeitsbereich. Sie ist ausdrücklich kein vollständiger Scan des Internets. Private Server werden weder gesucht noch dargestellt. Öffentlich sichtbare Infrastrukturpunkte stammen aus dem freiwilligen RIPE-Atlas-Messnetz; deren Positionen werden bereits durch RIPE zum Schutz der Betreiber räumlich verschleiert.

SOURCE // 01

Natural Earth

Die hochauflösende Ländergeometrie basiert auf dem frei nutzbaren 1:50m-Datensatz. Sie dient nur als kartografische Grundlage und behauptet keine Netzwerkaktivität.

MAP GEOMETRY // VERSIONED
SOURCE // 02

RIPE Atlas

Blaue Punkte sind echte verbundene öffentliche Messknoten aus einem datierten RIPE-Atlas-Snapshot. Für flüssige Darstellung wird eine reproduzierbare Auswahl gezeichnet; die vollständige verfügbare Anzahl und das Snapshot-Alter bleiben separat sichtbar.

PUBLIC MEASUREMENT NETWORK
SOURCE // 03

SANS ISC / DShield

Rote Regionen repräsentieren die aktivsten Quellnetze aus dem eingebundenen, datierten DShield-Snapshot. Das Alter des Snapshots wird in der Konsole ausgewiesen. Sie sind kein Identitätsnachweis und kein direkter JARVIS-Honeypot-Log.

EXTERNAL THREAT INTELLIGENCE
SOURCE // 04

DB-IP Lite

Quell-IP-Geodaten werden ausschließlich lokal mit DB-IP Lite nachgeschlagen und vor jeder Übertragung auf ein grobes Zwei-Grad-Raster reduziert. Dadurch entstehen echte regionale Linien ohne Roh-IP oder vorgetäuschte Punktgenauigkeit.

IP Geolocation by DB-IP // CC BY 4.0
SOURCE // 05

JARVIS Sensor Feed

Der grüne Bereich zeigt nur eine grosszügig verschleierte Zielregion. Der reale Cowrie-Sensor sendet ausschließlich minimierte, pseudonymisierte Ereignisse über einen HMAC-gesicherten Empfänger. Der Livezustand wird im Browser direkt aus der öffentlichen API geprüft.

01COWRIE SENSORisolierte Security-Node
02SANITIZE GATEIP entfernen, Region vergröbern
03PUBLIC APIsignierte Aggregate, Rate Limit

PRIVACY BOUNDARY // Der öffentliche Feed enthält keine Roh-IP, keinen echten Namen, keine Malware, keine Passwörter und keine vollständigen Eingaben. Detaillierte Sicherheitslogs bleiben geschützt und zeitlich begrenzt; die öffentliche Anzeige verwendet täglich wechselnde Pseudonyme und Zeitfenster-Aggregate.
