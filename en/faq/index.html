What is JARVIS OS?

JARVIS OS is an independent operating system project from Switzerland. It develops its own visible system path with UEFI boot manager, login, unified shell, control panel and real-time telemetry.

Is JARVIS OS simply a Linux distribution?

The current engineering status continues to use a Linux kernel, Linux drivers, and selected basic components. The visible boot, login, shell, and system layers are developed as a separate JARVIS product environment. This basis is not concealed.

Does JARVIS OS already have its own kernel?

No. A completely custom kernel and drivers are long-term research goals, but not yet finished components. Today, the Linux kernel and drivers remain for stable hardware access.

Can I download JARVIS OS?

Not yet. There is currently no public ISO. The download remains blocked until installation, recovery, secure boot and hardware portability have been sufficiently checked.

Will JARVIS OS only work on a specific laptop?

No, the system is explicitly designed for different real-world x86-64 PCs. The automatic hardware detection and broad bare metal test matrix are therefore binding release gates.

Can JARVIS OS be installed alongside Windows?

The boot manager is designed to detect existing boot targets. However, a public dual-boot path will only be released after discovery, selection, installation, and recovery have been safely tested on real systems.

Is the telemetry data real?

Technical ads should use real local sources. Unavailable values are marked as N/A. Decorative animations are referred to as such and may not be output as measurement data.

What does the public work signal transmit?

Only aggregated active status, duration, pulse and process count. It does not transmit chats, prompts, commands, file names, audio content, hardware IDs or IP addresses.

Who develops JARVIS SYSTEM?

The project was founded and developed by Oliver-frank Pristaff from Switzerland. Development is accompanied by structured documentation, reproducible builds and step-by-step testing.

How can I support the project?

The official Ko-fi support and membership channels are accessible. Payment never grants team, tester, moderator or system rights. The practical automatic assignment of supporter roles is checked in the first real case; until then, only the status documented and verified on the support page applies. Feedback and technical discussions are still possible free of charge via the Discord community.
