SYSTEM PROFILE // INDEPENDENT OS PROJECT

What is JARVIS OS?

JARVIS OS is the operating system kernel within JARVIS SYSTEM. The project is developing its own continuous operating path from the UEFI boot manager via login and system interface to the shell - clearly documented and for different real x86-64 PCs instead of just for a single VM.

01 // DEFINITION

A separate system path instead of just a new theme

JARVIS OS is not intended to feel like a regular Linux desktop environment with a different wallpaper. The visible flow is designed as a coherent product: hardware detection, system selection, login, shell, app control, telemetry and recovery follow the same technical language.

Below this separate layer, the current engineering status continues to use a Linux kernel, Linux drivers and selected basic components. This is stated openly. A completely custom kernel or a completely custom driver stack are long-term research goals, but are not yet finished product features.

02 // COMPONENTS

Which components already belong to JARVIS

The native EFI manager forms the visible preboot boundary. Your own login and runtime path then takes over. The Unified Shell connects commands, apps, and system information; the Frame Core gives opened applications a consistent JARVIS frame.

  • Native UEFI boot manager with mouse and keyboard controls
  • Own login and fingerprint orchestration with recovery path
  • Unified Shell for commands, app launch and control panel
  • Frame Core for JARVIS-style external application windows
  • True telemetry for CPU, RAM, network, storage, power and sensors
  • Community installer as a controlled engineering path

03 // PRINCIPLES

Honest data, controlled transitions and clear boundaries

A key rule is that if a value cannot be measured reliably, the system will show N/A instead of a made-up number. Animations may create atmosphere, but technical displays must come from real sources or be clearly labeled as decorative.

The same applies to project status and publications. A function is only considered verified once its associated test path has been documented. A successful VM test is valuable but does not replace proof of functionality across multiple real computers.

04 // PURPOSE

Who the system is intended for in the long term

JARVIS OS is aimed long-term at people who value control, technical overview and a strong development environment. The system should connect the operating system, toolbox and comprehensible system diagnostics.

There is no public ISO available for download yet. Installation, recovery, secure boot and the real hardware matrix must first reach a reliable release standard. Those interested can already follow the development via the public updates.

CURRENT RELEASE GATE // No public ISO until installation, recovery, secure boot and hardware portability have been robustly tested.
