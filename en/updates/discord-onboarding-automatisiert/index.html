DEVELOPMENT TRANSMISSION // COMMUNITY-02

Discord onboarding and role matrix automated

The JARVIS community now has a clean channel and role structure, a mandatory interest query before joining, and automatic, non-privileged role assignment.

2026-07-23VERIFIEDOliver-frank Pristaff
REPORT MATRIX01 // Legacy structure completely removed02 // Mandatory query before joining03 // Roles without manual activation04 // Fewer bots and smaller authorization area05 // Website and Discord are mutually connected← ALL UPDATES

01 // COMMUNITY-02

Legacy structure completely removed

All old channels and categories have been deleted. Of the old editable roles, only Member was retained for existing members upon express request. The visible server structure now consists exclusively of the new JARVIS areas System Entry, JARVIS SYSTEM, Developer Core, Test Lab, Community, Gaming, Voice Uplink and Staff Core.

02 // COMMUNITY-02

Mandatory inquiry before joining

Before joining, new members answer the question What are you interested in? Multiple selection is allowed. JARVIS OS & Development, Testing & Hardware and Community & Gaming each activate appropriate channels. The new welcome area and the Discord Server Guide form the common introduction.

03 // COMMUNITY 02

Roles without manual activation

Each selection automatically assigns COMMUNITY MEMBER and additionally OS & DEVELOPMENT, HARDWARE & TESTING or COMMUNITY & GAMING. These interest roles do not have moderation or administrative rights. The selection can be changed later via Channels & Roles.

04 // COMMUNITY-02

Fewer bots and smaller permission area

Member Count, ServerStats, Astro, Streamcord, Dyno, Graphite and TikTok have been removed. ProBot remains for moderation support, DISBOARD.org and Discord Me for server directories. No separate bot is required for role automation because Discord's native community onboarding takes over the task permanently.

05 // COMMUNITY 02

Website and Discord are mutually connected

The official community page at jarvisserver.org/community/ documents the structure, automation, security limits and release status and leads to the server via the permanent invitation link. In Discord, welcome, role, and update information points back to the official website and public development log.
